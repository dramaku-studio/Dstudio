Panduan & Ketentuan
Pelajari fitur, cara menggunakan studio, dan informasi penting untuk pengguna.


Alur tim internal
  1. Simpan cerita, lalu susun storyboard lokal.
  2. Impor gambar, klip, dan audio; simpan draf yang ingin dibagikan.
  3. Di Buat Video, pilih model/mode, lampirkan referensi, klik Uji Mode Lokal. Tes ini tidak menghasilkan video AI.
  4. Catat review aset, susun klip di Studio Film, lalu Render Film Lokal.
  5. Ekspor Paket Tim dari Proyek. Bagikan berkas .studio.json dan MP4 secara manual.
  6. Di komputer penerima, Impor Paket Tim dan konfirmasi ulang review sebelum merender.
Setiap komputer memakai API key dan kode akses sendiri. Berkas .local-private berisi kredensial dan tidak boleh dibagikan. Story export lama tetap tersedia untuk cerita saja. Paket tim mencakup sumber media hingga 64 MB; hasil render dapat diunduh terpisah.
AIIDE membutuhkan referensi HTTPS publik atau asset://mat_... yang dapat diakses akun yang benar. Mengimpor file lokal tidak mengunggah file itu ke AIIDE. Video Extend, model yang tidak terdokumentasi, serta generate gambar/suara/video berbayar tetap ditahan.
Render lokal memerlukan FFmpeg dan FFprobe. Buka Status Studio untuk memeriksanya. Versi ini untuk satu operator pada satu komputer; anggota lain berbagi paket proyek.

Cara menggunakan Dramasaku
  1. Buka Proyek & Cerita dan simpan ide karya.
  2. Atur karakter serta adegan di Storyboard.
  3. Masuk ke Buat Video, pilih model dan tulis arahan visual.
  4. Tambahkan referensi bila dibutuhkan, lalu simpan draf.
  5. Tinjau karya di Alur Produksi dan Riwayat.


Fungsi setiap menu
Studio Gambar untuk referensi visual, Studio Gerak untuk gerakan, Studio Suara untuk narasi, Studio Film untuk melihat hasil, Kunci API untuk mengatur layanan AI.


Kunci API dan biaya
Hanya admin yang boleh memasukkan API key. Setiap penyedia punya ketentuan, kuota, dan biaya sendiri. Batas harian Dramasaku tidak menggantikan batas asli penyedia. Pembuatan video berbayar tidak berjalan tanpa aktivasi dan persetujuan.


Privasi dan keamanan karya
Unggah hanya materi yang berhak Anda gunakan. Jangan mengunggah dokumen rahasia, wajah, suara, atau karya orang lain tanpa izin. Simpan kunci API hanya melalui halaman pengaturan, bukan di naskah atau deskripsi video.


Ketentuan penggunaan (draf)
Gunakan Dramasaku secara sah dan bertanggung jawab. Pengguna bertanggung jawab atas izin atas aset, hak cipta, persetujuan subjek, dan kelayakan konten. Fitur percobaan belum menjamin ketersediaan atau hasil akhir. Penggunaan layanan pihak ketiga tunduk pada kebijakan masing-masing penyedia. Ketentuan final perlu disetujui pemilik produk sebelum dirilis publik.


Informasi yang perlu diketahui pengguna
Model AI dapat menghasilkan hasil yang berbeda dari deskripsi. Periksa karakter, dialog, dan kualitas video sebelum publikasi. Hubungi admin studio untuk pertanyaan akun, saldo, persetujuan, atau laporan masalah.
