# CP-003 — Provider bridge, durable job lifecycle & playable fixture (implemented source, staging pending)

Date: 2026-11-05

## Newly implemented
- `packages/providers/src/http-video-bridge.mjs`: fixed-origin authenticated HTTP bridge, explicit POST semantics, no redirect, safe IDs, bounded status JSON.
- `packages/providers/src/fixture-bridge.mjs`: localhost HTTP test bridge, idempotent fixture task IDs.
- `packages/media/src/local-store.mjs`: size-limited streaming MP4 ingest, ffprobe validation, SHA-256, local private content-addressed storage (DEV ONLY).
- `packages/db/migrations/002_cp003_generation_jobs.sql`: durable generation jobs, media asset versions and tenant-aware references.
- `packages/db/src/generation.mjs`: queued→submitting→submitted→polling→ready, unknown/quarantine, no blind paid POST retry, cost/asset transaction, provider-failed billing lock.
- `packages/db/src/index.mjs`: optional generation input snapshot stored in the same atomic reservation transaction, replay hash validated.
- `apps/worker/production.mjs`: guarded PostgreSQL worker loop; no automatic paid execution.
- `apps/worker/demo.mjs`: real playable **ffmpeg fixture** MP4 via localhost HTTP bridge and checksum/ffprobe. Not AI-generated.
- CI/test additions and local preview hardening.

## Run locally (Node 22 + ffmpeg/ffprobe, no npm dependencies needed for demo)
```
npm test
npm run demo:video
# Open cp003-demo/index.html to play fixture video.
npm run preview
# Open http://127.0.0.1:4173 for CP-002 mock production dashboard.
```
