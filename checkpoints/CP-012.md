# CP-012 — Unified Creative UX, ID/EN and Multi-Key Routing

Date: 2026-11-05. Built on the single-app CP-011 source (CP-001 through CP-010 retained). CP-010 user-approved visual controls remain intact.

## Implemented

- Updated the **same canonical local UI**, `apps/control-server/ui.html` + `app.css` + `app.js` on port 4184, with creative-friendly navigation/copy and no internal checkpoint names in everyday screens.
- Added **Bahasa / Language (ID/EN)** selector; static UI and key settings translate in the browser. UI language is remembered locally; no API secret is stored in the browser. Dynamic content and full language QA for every page remain to be expanded before public release.
- Added **Bahasa arahan / Prompt language (ID/EN)** for Seedance draft metadata. This does **not** translate text automatically, invent new provider parameters, or modify the user-authored prompt.
- Added **Panduan & Ketentuan / Help & Terms** as a separate menu, with how-to steps, feature overview, key/billing explanation, consent/privacy reminders, user information, and a DRAFT terms section for product-owner/legal approval.
- Added two **independent key pools**: `creative` (LLM + Image if a provider supports both) and `video` (Seedance/video), with provider identity (`aiide`, `volcengine`, `google`, `openai`, `other`), unlimited named keys up to local max 50, priority 1–10, admin-defined daily request cap 1–100000, enable/disable, remove, routing policy priority or round-robin, and selection preview.
- Stored keys AES-256-GCM encrypted in `.local-private/key-pools.enc.json` with the local vault master key. Secrets are NEVER returned to the UI. Same credential cannot be saved twice for the same provider.
- All key routes are behind existing operator session + CSRF + loopback host/origin checks. No HTTP route exposes `reserveForInternalDispatch`; no paid request or provider balance sync exists.

## Local use

```bash
npm run dev
# Open http://127.0.0.1:4184 and sign in with the local operator token printed in the terminal.
npm test
```

Menu **Kunci API**: select Creative AI or Video AI, pick provider, enter label + key, set local daily request cap and priority, then save. To preview routing, choose matching group/provider and press `Cek Pilihan Kunci`. Nothing is charged or submitted.

## Operational truth / not done

- This is a **local operator prototype**, not a public multi-tenant key manager. The quota counts are **local request caps**, NOT real vendor credits, per-model cost limits, or shared account quotas.
- `reserveForInternalDispatch` is an internal test hook only. Do not wire it directly to paid provider submits. Production requires database transactional reservation, account-wide/provider caps, last-known vendor usage, model capability/price check, authorization, idempotency, reliable reconciliation, and no blind retry of ambiguous POST.
- AIIDE advertises a shared key across many models, but direct compatibility with **each video endpoint** must be verified; Volcengine Ark/LAS credentials and routes are separate and cannot be silently substituted.
- No public site deploy, GitHub push, Drive upload, paid API request, or external publishing occurred in this checkpoint.
- PostgreSQL live integrations and real provider entitlements/quotas remain unverified. The user-provided Drive folder named `__DRAMASAKU STUDIO` was readable and empty at audit time; nothing was written there.
