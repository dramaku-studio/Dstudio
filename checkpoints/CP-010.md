# CP-010 — Integrated visual generation controls

Source: continuation of CP-009, same `dramasaku-studio` monorepo. No separate project.

### Delivered
- Video Generate Studio: Seedance-native ratios 9:16, 16:9, 1:1, 4:3, 3:4, 21:9, Adaptive. Other common visual ratio presets (4:5, 5:4, 3:2, 2:3) are visible as disabled: Seedance cannot be sent unsupported ratios.
- Duration: step=1 second, model-specific 4–15s (2.0 tiers) or 4–30s (2.5); optional Auto where available and mandatory for 2.5 edit/extend.
- Conditional constraints on Seedance 2.5 aspect and duration enforced in both frontend and backend. Corrected overly strict 2.0 edit/extend aspect enforcement.
- Single integrated operator console, workflow and credential panel in one source tree.
- Regression tests across API, provider compiler and local console.

### Safety and limits
- Local prepared draft only; no paid API submission.
- Never use credential data in frontend preview or bundle.
- No proof of real PostgreSQL or vendor entitlement; production live remains NO-GO.

### Verification
Run `npm test` from the repository root. Two PostgreSQL integration tests require a real configured test server.
